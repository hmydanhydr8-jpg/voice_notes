# voice_notes

Voice Notes 🎙️

A simple Flutter voice recording application that allows users to record, save, play, pause, and delete audio recordings.

Features

- 🎙️ Record voice notes
- ⏱️ Display recording duration
- 💾 Save recordings locally on the device
- ▶️ Play and pause recordings
- 🎚️ Control playback position with a slider
- 🗑️ Delete recordings with a confirmation dialog
- 📋 Display saved recordings in a list

Technologies

- Flutter
- Dart
- "record" – audio recording
- "audioplayers" – audio playback
- "path_provider" – access to the application's local storage
- "dart:io" – file management

Purpose

This project was created as a learning project to practice working with audio recording, local file storage, playback controls, timers, and file management in Flutter.
